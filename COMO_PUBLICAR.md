# Como publicar seu README premium 💜🩷

Este pacote foi montado para o perfil https://github.com/annamelx e contém:

- `README.md`: conteúdo que aparece no perfil.
- `assets/banner.svg`: capa roxa/rosa personalizada.
- `assets/intro.svg`: saudação e subtítulo em rosa.

## Pelo celular (GitHub no navegador)

1. Entre em https://github.com/annamelx/annamelx e abra seu `README.md`.
2. Clique no lápis de editar, cole o conteúdo deste `README.md` e salve em **Commit changes**.
3. No mesmo repositório, abra **Add file → Upload files** e envie **banner.svg** e **intro.svg** para uma pasta `assets`.
   - Se a pasta ainda não existe, você pode criar com **Add file → Create new file**, usando o nome `assets/.gitkeep`, salvar e então enviar os SVGs dentro de `assets`.
   - Se o celular não permitir escolher a pasta, altere o modo de visualização do navegador para **Site para computador**.
4. Confirme que os arquivos estão nos caminhos exatos `assets/banner.svg` e `assets/intro.svg`. Se estiverem na raiz, os banners não aparecerão até ajustar o caminho no README.
5. No README, troque `SEU_EMAIL_AQUI` pelo seu e-mail verdadeiro (duas ocorrências).
6. Se já criou `.github/workflows/snake.yml`, acesse **Actions**, abra o workflow da cobrinha e use **Run workflow**. Espere ficar verde. A imagem só aparecerá depois que a branch `output` e o arquivo `github-contribution-grid-snake-dark.svg` existirem.

## Observações

- O GitHub decide a cor do fundo da página conforme o tema de quem acessa. O banner e o texto rosa são imagens e preservam suas próprias cores.
- O gráfico de estatísticas depende de serviços externos e pode ficar temporariamente indisponível.
- Para manter a arte, não mude os nomes dos arquivos nem a pasta `assets`.
- Você não precisa apagar o workflow da cobrinha que já criou.
